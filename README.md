
# SpecTec Mechanisation Backends and Type Soundness Proofs

This directory includes the codebase for the SpecTec mechanisation backends and
their associated type soundness proofs.

# Overview

This repository contains fours folders: `spectec/` contains the codebase for building
the SpecTec compiler. `wasm-definitions/` contains the SpecTec DSL code for the Wasm
1.0, Wasm 2.0 and Wasm 3.0. This can be used to test the executable generated when
building `spectec/` (see instructions below). `proofs/` contains the
mechanised type soundness proofs in all three proof assistants (Rocq, Isabelle and Lean)
and the correspondence proofs in Rocq and Isabelle.
The `interpreter/` folder can be ignored, it is only present to allow the files in 
the `spectec/` folder to also generate the interpreter backend.

# Building Spectec

SpecTec can be built using `opam` and *requires OCaml version 5.1.0 minimum*. We
recommend setting up a new opam switch to have a clean working environment:

```bash
opam switch create spectec-switch ocaml.5.1.0
```

Then follow the instructions given by opam to ensure the environment is correctly
synced with the newly created switch.

Now running

```bash
make
```

inside the `spectec/` repository will install all necessary dependencies and build an
executable `spectec/spectec` than can then be run on SpecTec DSL code, e.g. the definitions
of wasm 1.0, 2.0 or 3.0 present in `wasm-definitions/`. Use options `--rocq`, `--isabelle`
and `--lean` to generate code in the three proof assistants, e.g.

```bash
spectec/spectec --isabelle wasm-definitions/wasm-2.0/* -o wasm2_in_isabelle.thy
```

Note that the output code will contain proof obligations corresponding to well-formedness
lemmas. These must be proved manually, as we have done in `proofs/`.

# Browsing the Code for the Backends

The code that builds the SpecTec exucutable is in `spectec/src/`. Some documentation
is available in `spectec/doc/` to understand the intermediate representations.

The contents of `spectec/src/` are divided into folders that should make navigation intuitive.
We only mention the most important files:

- The point of entry is in `spectec/src/exe-spectec/main.ml`
- The AST for the intermediate language (IL) is in `spectec/src/il/ast.ml`
- The numerous IL-to-IL passes are in `spectec/src/middlend/`
- The Rocq backend is in `spectec/src/backend-rocq/print.ml`
- The Isabelle backend is in `spectec/src/backend-isabelle/print.ml`
- The Lean backend is in `spectec/src/backend-lean/backend.ml`

# Browsing the Proofs

Repository `proofs/` contains three folders: `proofs/rocq/`, `proofs/isabelle/` and `proofs/lean/`,
each containing a folder named `type-soundness/` than contains the type soundness proof for Wasm 2.0
for its corresponding proof assistant.
The `proofs/rocq/` and `proofs/isabelle/` folders also contain a folder names `correspondence/`
which contains a proof of correspondence between the generated code and WasmCert. WasmCert-Rocq is
imported via opam by the Rocq files; the WasmCert-Isabelle files are present in `proofs/isabelle/`
explicitly. 

The mechanised definitions generated by the spectec executable from `spectec/` (see above)
have been used as the starting point for the proofs. These can be generated using the executable,
or can be found together with the type soundness proofs:

- `proofs/rocq/type-soundness/wasm.v` for Rocq
- `proofs/isabelle/type-soundness/isabelle_reference_output_wasm2.thy` for Isabelle
- `proofs/lean/type-soundness/wasm2.0.lean` for Lean

The Rocq proofs can be built by running

```bash
make
```

in the `proofs/rocq/` repository.

The Isabelle proofs can be built and inspected by opening jEdit. Information on how to install
jEdit is available online. Files `proofs/isabelle/type-soundness/Progress.thy`
and `proofs/isabelle/correspondence/backreduction.thy` are the endpoints, running them will
run all other files.

The Lean proofs can be built by running `lake build`.
